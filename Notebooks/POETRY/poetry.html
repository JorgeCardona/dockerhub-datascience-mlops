Super Guía Definitiva de Poetry 2.5.1: Arquitectura, Comandos y Entornos

Guía exhaustiva con los Conceptos Fundamentales, Ciclo de Vida, Configuración Completa de Entornos Virtuales y el Catálogo de Comandos Poetry CLI.

1. Conceptos Fundamentales de Poetry

¿Qué es pyproject.toml? (Configuración)

Archivo estándar TOML para declarar metadatos, versión de Python compatible y dependencias del proyecto.

Qué genera poetry init: Crea automáticamente este archivo interactuando contigo para definir nombre, autor, versión y dependencias iniciales.

¿Qué es poetry.lock? (Reproducibilidad)

Archivo que congela las versiones exactas y hashes criptográficos de todas las dependencias directas e indirectas.

¿Qué es el Entorno Virtual? (.venv)

Carpeta aislada con su propio binario de Python y librerías independientes del sistema operativo.

¿Qué es poetry new? (Estructura)

Crea una nueva estructura de paquetes completa con carpetas src/, tests/ y configuración inicial lista para publicar en PyPI.

2. Ciclo de Vida y Gestión de Entornos Virtuales (.venv) en Poetry

Poetry administra automáticamente el entorno virtual. Aquí tienes cómo habilitarlo, deshabilitarlo, cambiar su ubicación y establecer nombres personalizados (carpetas tipo .venv).

Habilitar / Deshabilitar Creación del .venv

Controla si Poetry debe crear un entorno virtual de manera automática al instalar dependencias:

# Habilitar (Por defecto):
poetry config virtualenvs.create true

# Deshabilitar (Usar entorno global del sistema):
poetry config virtualenvs.create false

Ubicación y Nombre Personalizado (.venv)

Por defecto Poetry guarda los entornos en la caché global del sistema operativo (ej. ~/Library/Caches/pypoetry/virtualenvs/). Para crear una carpeta local llamada exactamente .venv dentro de tu proyecto:

# Forzar entorno dentro del directorio del proyecto:
poetry config virtualenvs.in-project true

# Volver al almacenamiento global fuera del proyecto:
poetry config virtualenvs.in-project false

Selección de Versión de Python

Define explícitamente qué binario de Python utilizará el entorno virtual antes de instalar o ejecutar dependencias:

# Asignar intérprete específico:
poetry env use python3.12
poetry env use /usr/bin/python3.11

Ejemplo Práctico del Flujo de Creación y Activación

Paso 1 Configurar almacenamiento local:
poetry config virtualenvs.in-project true
Paso 2 Seleccionar Python:
poetry env use python3.12
Paso 3 Crear entorno e instalar:
poetry install
(Genera la carpeta .venv/)
Paso 4 (Opcional) Activar manualmente:
source .venv/bin/activate
(O usar poetry run ...)

3. Catálogo Completo y Exhaustivo de Comandos Poetry CLI

Desglose absoluto de cada comando de Poetry con opciones avanzadas, archivos involucrados y ejemplos prácticos de ejecución.

Comando Poetry Categoría ¿Cómo funciona y de dónde sale? Cuándo usarlo Ejemplo Detallado y Opciones Avanzadas
poetry init INICIO
  • Asistente interactivo que genera el archivo pyproject.toml preguntando por nombre, autor y dependencias iniciales.
 Al iniciar un proyecto de Python completamente nuevo desde cero.
Comando TerminalBASH
poetry init --no-interaction
Efecto: Crea un pyproject.toml con valores por defecto sin requerir respuestas interactivas.
poetry new INICIO
  • Crea la estructura de carpetas estándar para una nueva librería o paquete de Python, incluyendo tests y pyproject.toml.
 Cuando vas a desarrollar un paquete reutilizable destinado a ser publicado en PyPI.
Comando TerminalBASH
poetry new mi_paquete --src
Efecto: Crea la carpeta mi_paquete/ con diseño de layout en src/.
poetry add DEPENDENCIAS
  • Conecta con PyPI, analiza el árbol de dependencias existente (versión de Python y paquetes ya instalados) y busca de forma automática la versión compatible. Permite fijar versiones exactas, rangos personalizados o comodines abiertos entre comillas.
 Cada vez que necesitas incorporar una nueva librería o dependencia externa al proyecto.
Comando Terminal (Manejo de Versiones, Rangos y Comodines)BASH
# 1. Versión fija exacta (congela estrictamente el paquete a esa versión): poetry add yamllint==1.35.1 # 2. Rango controlado y seguro (permite actualizaciones menores compatibles '^'): poetry add yamllint # 3. Rango explícito personalizado (ej. versiones superiores a 1.33 y menores o iguales a 1.35): poetry add "yamllint>1.33,<=1.35" # 4. Comodín abierto con comillas para buscar y aceptar automáticamente cualquier versión compatible: poetry add "yamllint=*"
Por qué se usa "yamllint>1.33,<=1.35" o "yamllint=*": Permite definir restricciones de rangos personalizados o dejar que Poetry analice el árbol de dependencias actual y encuentre de forma automática la versión compatible óptima disponible en el índice.
WARNING: Usar comodines abiertos como "yamllint=*" puede introducir versiones mayores incompatibles si no se manejan rangos seguros en entornos de producción estrictos. Es preferible usar rangos controlados (ej. ^1.0.0 o "yamllint>1.33,<=1.35") o versiones fijas exactas (ej. yamllint==1.35.1) para evitar roturas inesperadas en producción.
poetry remove DEPENDENCIAS
  • Elimina una dependencia de pyproject.toml, regenera el lock y la desinstala del entorno virtual.
 Cuando una librería ya no es necesaria en la arquitectura del proyecto.
Comando TerminalBASH
poetry remove "yamllint"
Efecto: Limpia la dependencia del entorno y archivos de configuración.
poetry install DEPENDENCIAS
  • Lee estrictamente el archivo poetry.lock e instala las versiones exactas congeladas en el entorno virtual.
 Al clonar un repositorio, tras un git pull o para configurar el entorno del equipo.
Comando TerminalBASH
poetry install --without dev --no-root
Efecto: Útil en contenedores Docker para instalar únicamente lo indispensable.
poetry update DEPENDENCIAS
  • Revisa las versiones disponibles en PyPI dentro de los rangos permitidos y actualiza el poetry.lock.
 Para actualizar dependencias de forma controlada a sus últimas versiones compatibles.
Comando TerminalBASH
poetry update "pandas"
Efecto: Actualiza únicamente el paquete pandas y sus dependencias directas.
poetry lock DEPENDENCIAS
  • Calcula y actualiza el archivo poetry.lock basado en pyproject.toml sin realizar instalaciones físicas.
 Cuando modificas restricciones de versión manualmente en el toml y necesitas regenerar el lock.
Comando TerminalBASH
poetry lock --no-update
Efecto: Regenera el lock manteniendo las versiones actuales si siguen siendo válidas.
poetry sync DEPENDENCIAS
  • Sincroniza el entorno virtual con el lock, eliminando automáticamente paquetes huérfanos o sobrantes.
 En servidores de CI/CD o entornos donde requieras una sincronización estricta.
Comando TerminalBASH
poetry sync
Efecto: Garantiza que el entorno virtual contenga exactamente los paquetes del lock.
poetry show DEPENDENCIAS
  • Lista todos los paquetes instalados en el entorno virtual con sus versiones y descripciones.
 Para auditar dependencias o verificar actualizaciones con --outdated.
Comando TerminalBASH
poetry show --tree poetry show --outdated
Efecto: Muestra dependencias en formato de árbol y lista paquetes desactualizados.
poetry env info ENTORNOS
  • Muestra información detallada sobre el entorno virtual activo (ruta, versión de Python, ejecutable).
 Para configurar editores como VS Code o depurar rutas del sistema.
Comando TerminalBASH
poetry env info --path
Efecto: Devuelve la ruta absoluta del entorno virtual actual.
poetry env list ENTORNOS
  • Lista todos los entornos virtuales asociados al proyecto actual en el sistema operativo.
 Когда tienes múltiples entornos virtuales creados o quieres verificar el activo.
Comando TerminalBASH
poetry env list --full-path
Efecto: Muestra la lista completa con rutas detalladas de cada entorno.
poetry env use ENTORNOS
  • Selecciona y activa una versión específica de Python para asociarla al entorno virtual del proyecto.
 Antes de instalar dependencias, para configurar el intérprete deseado.
Comando TerminalBASH
poetry env use python3.12
Efecto: Configura el entorno virtual utilizando Python 3.12.
poetry env remove ENTORNOS
  • Elimina de forma física el entorno virtual asociado del sistema operativo.
 Когда necesitas reconstruir el entorno desde cero por corrupción o cambio de versión.
Comando TerminalBASH
poetry env remove python3.12
Efecto: Borra la carpeta del entorno virtual liberando espacio en disco.
poetry run ENTORNOS
  • Ejecuta cualquier comando o script inyectando las variables de ruta del entorno virtual aislado.
 Para ejecutar scripts de Python, pruebas con pytest o herramientas CLI como dbt.
Comando TerminalBASH
poetry run python main.py
Efecto: Ejecuta el script dentro del entorno virtual sin activación manual previa.
poetry shell ENTORNOS
  • Genera una nueva sub-shell interactiva en tu terminal con el entorno virtual activado automáticamente.
 Когда necesitas trabajar en una sesión interactiva prolongada en el entorno.
Comando Terminal (Para salir usar exit)BASH
poetry shell
Efecto: Activa el entorno virtual en la sesión actual de la terminal.
poetry check VALIDACIÓN
  • Valida la sintaxis del archivo pyproject.toml y verifica su consistencia con el lock.
 Antes de confirmar cambios en Git o al experimentar fallos de dependencias.
Comando TerminalBASH
poetry check
Efecto: Retorna "All set!" si todo está correcto.
poetry config CONFIGURACIÓN
  • Muestra o modifica parámetros de configuración global o local de Poetry (ej. ubicación de .venv).
 Al configurar un nuevo equipo o ajustar comportamientos predeterminados.
Comando TerminalBASH
poetry config --list poetry config virtualenvs.in-project true
Efecto: Configura la creación local del entorno en formato .venv.
poetry export EXPORTACIÓN
  • Exporta las dependencias resueltas en el lock a formatos tradicionales como requirements.txt.
 Para interoperabilidad con herramientas heredadas de infraestructura o pip.
Comando TerminalBASH
poetry export -f requirements.txt -o requirements.txt --without-hashes
Efecto: Genera un archivo requirements.txt idéntico al lock.
poetry search DEPENDENCIAS
  • Busca paquetes disponibles en el índice de PyPI directamente desde la terminal.
 Когда quieres explorar nombres de librerías o verificar disponibilidad.
Comando TerminalBASH
poetry search "yamllint"
Efecto: Retorna las coincidencias de paquetes en PyPI.
poetry publish PUBLICACIÓN
  • Empaqueta y publica tu librería o paquete desarrollado directamente en PyPI o un repositorio privado.
 Когда finalizas el desarrollo de un paquete open source o interno.
Comando TerminalBASH
poetry publish --dry-run
Efecto: Simula la publicación validando que todo el empaquetado sea correcto.
poetry build CONSTRUCCIÓN
  • Genera los artefactos de distribución del paquete en formatos sdist (.tar.gz) y wheel (.whl).
 Перед de publicar o distribuir tu paquete localmente.
Comando TerminalBASH
poetry build
Efecto: Crea los archivos compilados en la carpeta dist/.
poetry cache MANTENIMIENTO
  • Gestiona la caché interna de Poetry para limpiar descargas y optimizar almacenamiento.
 Когда experimentas problemas de caché corrupta al instalar dependencias.
Comando TerminalBASH
poetry cache clear --all pypi
Efecto: Limpia completamente la caché de descargas de PyPI.
